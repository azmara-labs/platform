Add `@azmr/ui/toast`: a `Toaster` and an imperative `toast` API (`toast.success`, `error`, `info`, `warning`, `loading`, `promise`, `update`, `dismiss`). Toasts stack, dedupe by id, pause while hovered or focused, can be swiped away, take an action such as Undo, and are announced politely (errors urgently). Six positions, on the `--z-toast` layer.
