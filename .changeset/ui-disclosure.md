Add `@azmr/ui/disclosure`: `Accordion`, `Collapsible` and `Tabs` (horizontal and vertical), built on Base UI with token styling, heading-wrapped accordion triggers, full keyboard maps (including accordion arrow navigation, which Base UI 1.9 does not implement) and height animation that follows the motion tokens. Add `useUrlTab` to `@azmr/ui/hooks`, which keeps the selected tab in a search parameter and ignores any value not in the allowed list.
