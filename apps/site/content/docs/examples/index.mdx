A component page shows one component. These pages show how they fit together: a form, a table, an app shell, a destructive action and a multi-step flow. Each is a real component you can copy into an app. Every example is rendered and checked with axe by the docs tests, so none of them can quietly break.

| Example | What it shows | Built from |
| --- | --- | --- |

## How to read them

Each page has the live example, the source under it, what the example is demonstrating and the choices that matter for accessibility. The source imports only from `@azmr/ui`, `react` and `lucide-react`, so you can paste it into an app that has [installed the package](/docs/components#set-up).

Use the preview switches above each example to see it in light and dark and at each density. For the smaller, single-purpose patterns, see the [recipes](/docs/recipes).

## What the examples do not cover

`@azmr/ui` has no select, checkbox, radio, switch or textarea yet, so the forms here use the text input and toggle buttons. They are not wired to a server or a form library: the save is a timer. Where an example stands in for something real, the page says so.
