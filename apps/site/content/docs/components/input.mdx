## Usage

```tsx
import { Input, Textarea } from "@azmr/ui/input";
```

<Demo name="input/basic" />

Every input needs a visible label. Wrap it in a [`Field`](/docs/components/field), which adds the label, description and error and wires them up, or use your own `<label htmlFor>` (or `aria-label` when the design has no label).

## States

<Demo name="input/states" />

Inside a [`Field`](/docs/components/field), pass `error` and this is done for you. On its own, `aria-invalid="true"` styles the error state and is what assistive technology announces; point `aria-describedby` at the message so it is read with the field. A read-only input stays focusable and can be selected and copied, while a disabled one is skipped by Tab.

## Textarea

<Demo name="input/textarea" />

`Textarea` is a real `<textarea>` with the same styling, states and value API as `Input`. It shows three rows by default and resizes vertically; `autoResize` makes it grow with its content instead (CSS `field-sizing: content`; browsers without it keep the fixed height).

## With react-hook-form

The `ref` is the real `<input>`, so `register()` works directly:

```tsx
import { useForm } from "react-hook-form";
import { Input } from "@azmr/ui/input";

function EmailField() {
  const { register } = useForm<{ email: string }>();
  return <Input type="email" {...register("email")} />;
}
```

Native `onChange` and a typed `onValueChange(value)` both fire. `Textarea` works the same way. To show the error from `formState.errors`, see [Field with react-hook-form](/docs/components/field#with-react-hook-form).

All native `<input>` attributes pass through. `className` is merged last, so it can override the defaults, and `onValueChange` gives you the new value directly instead of `event.target.value`.

Height and horizontal padding follow the density tokens, so the input lines up with `Button` at every density.

## Accessibility

- A real `<input>`: name, role and value come from the platform.
- The focus ring is full strength (WCAG 2.2 focus appearance), never faded.
- Invalid state is exposed through `aria-invalid`, not colour alone: pair it with a text message.
