This guide adds `@azmr/ui` to a React Router app in framework mode, which is the successor to Remix and is built with Vite. It takes about five minutes. If you do not have an app yet, create one with `npx create-react-router@latest my-app`; everything below is what you add or change. For a Remix v2 app, upgrade to React Router first.

## 1. Install

```bash
pnpm add @azmr/ui @azmr/core
# or
npm install @azmr/ui @azmr/core
```

`react`, `react-dom` and `react-router` are already in your app. `@azmr/core` is a peer dependency, so install it yourself: see [Installation](/docs/guide/installation#the-four-steps).

## 5. Add dark mode

With no setup at all the page already follows the operating system. To let people choose, the root above reads a saved choice from the cookie in its `loader` and renders it onto `<html>`, so the first paint is already in the right mode. It also wraps the routes in `ThemeProvider`, which remembers a new choice in the cookie. A component changes it with `useTheme()`:

<FixtureFile file="react-router/app/theme-toggle.tsx" />

Density works the same way: `useTheme()` also returns `density` and `setDensity`, with the values `compact`, `comfortable` and `spacious`.

## What was tested

The files above are the files of an app that CI builds. On every change it packs `@azmr/ui` into a tarball, installs it into that app, type-checks (including React Router's generated route types) and builds it, starts the server and checks that:

- the page renders the Button and the label on the server;
- Tailwind generated the Button's and Input's classes from the two class lists the stylesheet imports, and nothing else from the package;
- the colour tokens are in the stylesheet;
- a `dark` cookie renders `data-theme="dark"` on `<html>`, and no cookie renders no attribute.
