A recipe is one task, answered in one screen. For whole pages built from many components, see the [examples](/docs/examples).

| Recipe | The task |
| --- | --- |
| [Validate a form](/docs/recipes/form-validation) | Show an error next to a field, in a way a screen reader hears, and put focus on it. |
| [Show a toast while a promise runs](/docs/recipes/toast-on-promise) | Report loading, success and failure of one async call. |
| [Open a dialog from a menu item](/docs/recipes/menu-opens-dialog) | Confirm something chosen from a menu, without the dialog closing with the menu. |
| [Give each tenant its own theme](/docs/recipes/theme-per-tenant) | Apply a brand colour from data to one part of a page. |
